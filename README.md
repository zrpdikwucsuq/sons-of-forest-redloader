## Overview

RedLoader is a BepInEx-compatible mod loader for Sons of the Forest that handles mod installation, dependency management, and provides a C# API for game object access. It powers the majority of the Sons of the Forest mod ecosystem and features an in-game mod menu for toggling installed mods without restarting.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sons of the Forest RedLoader** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Mod Loader Core** | Foundation framework for all C# and Harmony-based SOTF mods |
| **In-Game Menu** | Toggle installed mods on and off from within the game without restarting |
| **Dependency Resolution** | Automatically downloads and manages mod dependency chains |
| **BepInEx Compat** | Supports BepInEx-compatible plugins alongside native RedLoader mods |
